# 高云 EDA（云源软件）下载指引

> 下载必须**登录高云官网账号**（带验证码），无法自动化，需队员手动完成。

## 步骤（约 10 分钟）
1. 打开高云软件下载中心：<https://www.gowinsemi.com.cn/software_share>
2. **注册/登录**账号（建议用学校邮箱，可申请免费 License）
3. 找到 **Gowin EDA（云源软件）For Linux**，选择**支持 GW5AT 系列**的版本下载
4. 同时到 **profile/license** 申请免费 License
5. 下载完成后，把安装包**放到 ~/Downloads** 并告诉 Codex「高云 EDA 下载好了」，由 Codex 帮忙安装进项目 `开发/工具/gowin-eda/`

## 注意
- 文件较大（可能数 GB），请预留磁盘空间
- Linux 版通常是自解压安装包或 tar 包
- 装好后主要用于：**综合（synthesis）+ 布局布线 + 生成比特流**（等板卡 9/20 到后使用）
- 学习 Verilog 和 RTL 仿真目前用 iverilog 即可（已装好）
