## 一、IMU 是什么？（先搞懂概念）

**IMU = Inertial Measurement Unit（惯性测量单元）**
相当于机器人的「内耳前庭 + 平衡感」，用来感知自己的姿态和运动。

### 里面有什么
| 传感器 | 测什么 | 类比 |
|---|---|---|
| 加速度计 (Accelerometer) | 3 轴加速度 | 感觉「自己在往哪加速/被重力拉向哪」|
| 陀螺仪 (Gyroscope) | 3 轴角速度 | 感觉「自己转得有多快」|
| 磁力计 (Magnetometer，可选9轴) | 3 轴磁场 | 像「指南针」，定东西南北 |

### 能算出什么
- **横滚角 Roll / 俯仰角 Pitch**：由加速度计+陀螺仪融合（互补滤波 / 卡尔曼滤波）
- **偏航角 Yaw**：由陀螺仪积分 + 磁力计校正
- 这些就是选题三任务1 要求的「**姿态角信息**」

### 常见芯片（选型参考）
| 芯片 | 轴数 | 特点 |
|---|---|---|
| MPU6050 | 6 轴 | 最常见、便宜、资料多（推荐入门）|
| ICM-42688 | 6 轴 | 更小、精度更高、支持 SPI |
| BNO055 | 9 轴 | 内部自带姿态解算，直接输出欧拉角，最省事 |

> 接口：I2C 或 SPI，都适合 FPGA/单片机读取。

## 二、底盘选型建议（买成品 vs 从零）

### 硬性要求（由任务2/4决定）
必须能提供：**电机 + 编码器(AB相) + 电机驱动 + 轮子**
- 编码器 → 测速/里程计（任务2 闭环、任务4 导航都用它）

### 方案对比
| 方案 | 优点 | 缺点 | 建议 |
|---|---|---|---|
| **买成品底盘**（推荐） | 省时间、结构可靠 | 灵活性低 | 先把时间花在 FPGA+AI 上 |
| 从零设计 | 完全定制 | 周期长、需机械/结构人才 | 除非队伍有结构高手，否则不推荐 |

### 买什么
- **普通双驱 + AB 编码器**：够任务2/3/4，性价比高
- **麦克纳姆轮（全向底盘）**：能横移，**创新加分**，但控制更复杂
- 注意确认：电机驱动板接口（PWM+方向？还是 CAN？）、编码器输出（AB相正交）

### 机械臂（可选，加分项）
- 旧框架 `usb.arm` 可复用 → 做「找到目标→抓取」演示，冲**创新设计 10%**

## 三、开发环境搭建（现在就能做）

### A. FPGA 侧：高云云源 EDA（Gowin EDA）
1. 打开 <https://www.gowinsemi.com.cn/software_share>（软件下载中心）
2. 找到 **Gowin EDA（云源软件）**，下载支持 **GW5A / GW5AT 系列** 的最新版
   （你们的芯片是 GW5AT-60K，注意版本需覆盖 5A/5AT 系列）
3. 安装（Windows 或 Linux 均可；一般需注册账号 / 学校邮箱申请 License）
4. 可以先建**空工程**熟悉流程：
   新建工程 → 选芯片 GW5AT-LV60PG484A → 写个 LED 闪烁 Verilog → 综合/仿真
   （仿真不需要板子，能提前练手）

> 学习资源：高云官网「开发者中心 / 文档中心」、B站高云官方课程。

### B. RK3588 侧（板子到货后，但工具可先装）
- 板卡配套 **Linux 镜像 / SDK**：随板子由小梅哥提供（9/20 后）
- **现在在电脑上先装**（开发 RK3588 端程序要用）：
  ```bash
  # Python + 视觉库
  python3 -m pip install ultralytics opencv-python pyserial numpy
  # YOLO 需要 torch（先用 CPU 版测试即可）
  python3 -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
  ```
- 旧框架的 `ultralytics-main` 视觉代码，**现在就能在电脑上 + 摄像头跑起来**（不依赖板子）

### C. 通信调试工具
- 串口助手（Windows: SSCOM / 友善串口助手；Linux: minicom / cutecom）
- MobaXterm（Linux 板子 SSH 终端 + 文件传输，强烈推荐）

## 四、团队分工建议（假设 4-5 人，可按人数调整）

| 角色 | 人数 | 负责内容 | 对应任务 |
|---|---|---|---|
| **FPGA 工程师** | 1-2 | 高云 EDA、Verilog：编码器解码、PID 电机控制、超声避障、IMU 读取、FPGA↔CPU 通信 | 任务1/2/3/4 实时侧 |
| **系统/嵌入式** | 1 | RK3588 Linux、BSP、串口/驱动、系统集成、稳定性 | 全局 |
| **算法/视觉** | 1 | YOLO 目标检测/跟踪、导航规划、图像显示 | 任务1/4/5/6 |
| **硬件/机械** | 1 | 底盘选型、接线、电源、传感器、机械臂 | 全局 |
| **文档/测试**（可兼职） | 1 | 设计文档、测试报告、答辩 PPT | 评审 |

### 分工原则
- **FPGA 实时性**（40% 分）和 **稳定性**（25%）最重要 → 配最强的两人
- 视觉/导航（20%+5%）→ 给擅长 Python/算法的
- 先按角色各自装好环境，再一起定**通信协议**
