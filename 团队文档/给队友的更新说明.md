## 二、你为什么要 pull

因为远程仓库已经变了，**不 pull 的话，你本地和远程会不一致**，下次 push 可能被拒绝或产生冲突。

## 三、怎么 pull（重要！先看这里）

### 如果你本地【没有】未提交的改动（推荐）

直接执行：
```bash
git pull
```

### 如果你本地【有】未提交的改动

**先提交或保存你的改动，再 pull**，否则可能冲突：

```bash
# 1. 先看自己有没有改动
git status

# 2. 有改动就先提交
git add -A
git commit -m "本地改动提交"

# 3. 再拉取
git pull
```

如果 pull 时报冲突，**不要慌**，把报错信息发到群里，我们帮你解决。
