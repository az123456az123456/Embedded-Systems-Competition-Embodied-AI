## 目录结构

```text
团队文档/
├── README.md                 ← 本文件（入口）
├── 需求与设计/               选题分析、旧框架能力边界、匹配分析图
├── 团队规范/                 Git 规范、分工、通知
├── 开发环境/                 EDA、视觉环境、下载指引
├── 进度/                     工作清单 + 协作记录 + 功能说明
└── 技能库/                   Codex 技能（踩坑沉淀）
```

## 新增文档规则

1. 功能/代码说明优先写在对应代码模块的 `README.md`
2. 团队级说明放 `团队文档/` 对应分类目录
3. 协作记录追加到 `团队文档/进度/`
4. 踩坑解法沉淀到 `团队文档/技能库/`
