# YOLO 与 IMU 统一窗口

> 2026-10-15 · ACG138 / RK3588 Buildroot

## 🖥️ 新入口

代码位于 `小车代码汇总/代码/2026新开发/rk3588/perception_dashboard/`，使用 `run-perception.sh`。

| 内容 | 结果 |
|---|---|
| 统一窗口 | Wayland 原生视频、检测框、姿态角和加速度；保留校准/归零 |
| 双目识别 | 左右分别推理，可选 both/left/right/single；每眼独立 NMS |
| 输入修正 | 采用协商尺寸/格式/stride/平面；安全 YUV→RGB；错误帧不推理 |
| 输出修正 | 严格验证 6/9 路分支；稳定 DFL；逆变换后按单眼 ROI 裁剪 |
| 实时性 | 工作线程推理，窗口/IMU 接收独立；及时归还相机缓冲，无定期 PNG 写盘 |
| 模型 | 沿用当前 YOLO/model.rknn，未训练新权重 |
| 验证 | 主机测试、实际 ONNX 离线对照、窗口协议测试和 ARM64 编译通过 |
| 板端启动参数 | 用户日志已确认 `/dev/video41`、9 路 FP16 模型、`/run/wayland-0`；v2 启动器复用 find-video/ISP 准备及旧模型/库目录 |
| 待实板确认 | 新统一程序 NPU/采集运行、IMU 接口和实际场景精度 |

预编译 ELF 要求 glibc ≥ 2.33；使用板上原有 RKNN/Wayland 库。源码/验证记录、模型兼容限制与操作步骤见模块 README.md。原 YOLO、IMU 独立窗口及历史框架保留。

本次不能用示例图检测成功推断实际场景 mAP 提升。先修复输入/坐标链路，再用同一批实拍标注数据比较；是否微调或升级模型由这个对比决定。
