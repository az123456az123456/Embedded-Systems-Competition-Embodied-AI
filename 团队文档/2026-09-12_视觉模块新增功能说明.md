# 视觉模块新增功能说明（RK3588 侧）

> 日期：2026-09-12
> 代码位置：`小车代码汇总/代码/rk3588/`
> 对应：**任务5 视觉目标识别** + **任务6 智能任务执行**

---

## 一句话总结

在旧框架「颜色检测（ultralytics-main）」的基础上，新增了 **YOLO 目标检测 + 多目标跟踪 + 颜色定位 + 人员重识别 + 任务执行状态机**，把原来「检测 → 打印」的开环，升级成「搜索 → 靠近 → 到达」的闭环，并预留了给 FPGA 下发的串口指令与测距接口。

## 新增功能一览

| 新增功能 | 作用 | 文件 |
|---|---|---|
| YOLOv8n 目标检测 + ByteTrack 多目标跟踪 | 识别人员/物体并连续跟踪（旧框架只有颜色检测） | `task6_mission.py` / `vision_demo.py` |
| HSV 颜色判定（红/绿/蓝） | 定位「红色水瓶」这类目标 | `vision_demo.py` |
| 深度 ReID 人员重识别 | 外观 + 空间双特征匹配，另有「空间连续性兜底」，被遮挡再出现 ID 不变 | `deep_reid.py` + `task6_mission.py` |
| 任务6 状态机 | `SEARCH → LOCK → ALIGN → APPROACH → ARRIVE`，把散装能力串成自主执行 | `task6_mission.py` |
| 串口运动指令（占位协议） | `$M,<CMD>,<arg>!` 下发前进/转向/停车给 FPGA | `task6_mission.py` |
| 占位测距 | 用检测框高度比例近似「够近」（待换成 FPGA 超声波） | `task6_mission.py` |

## 任务6 状态机

```
SEARCH ──连续 N 帧有目标──▶ LOCK ──▶ ALIGN ──▶ APPROACH ──▶ ARRIVE
   ▲                          │                              │
   └──── 任意状态连续丢目标 ────┘        （未对准/目标跑了会退回 ALIGN/APPROACH）
```

每个状态转换都做「连续 N 帧确认」，抗单帧抖动；到达必须「对准 + 够近」同时成立。

## 与旧框架的关系

- **旧框架**：`ultralytics-main` 只做颜色检测，输出即打印（开环）。
- **新增**：检测/跟踪/重识别 + 闭环决策 + 串口运动指令，覆盖任务5「跟随」和任务6「找目标移动」。

## 怎么跑（板子到货前先在 PC 上验证）

```bash
cd 小车代码汇总/代码/rk3588
pip install -r requirements.txt          # 换机器时
python task6_mission.py --target bottle --target-color red   # 找到红色水瓶并靠近
```

> 深度 ReID 权重 `yolov8_reid/*.pth` 与检测权重 `yolov8n.pt` 体积大、已 gitignore，需单独下载（见 `requirements.txt` 备注与 `改进清单.md`）。
