# ACG138：FMC 四电机测试 v3 方向与PWM调整版

> 2026-10-13 · TB6612 · STBY外接常高 · 20kHz PWM

本目录保留旧版逐轮正反转示例、FMC 引脚资料和回归测试。当前分级负载诊断使用相邻的 [`fmc_four_load_diag_direction_v2_20261019`](../fmc_four_load_diag_direction_v2_20261019/README.md)：实测轮位为 M1右后、M2左后、M3右前、M4左前，方向掩码为 `0000`。本目录 v3 的默认掩码仍为 `1100`，流程和方向约定不同，烧录前按所选工程核对。

## 🔧 本次修改与排查结论

你已确认电机额定12V，TB6612逻辑VCC为3.3V、VM接外部12V；四轮悬空时匀速段仍持续卡顿，已报告电源12V/6A，运行时VM与驱动温升尚未实测。

v3保持已跑通的v2引脚，按反馈将M3/M4电气方向取反。INVERT_MASK=4'b1100，bit0～3对应M1～M4。逻辑前进时M1/M2为IN1=1、IN2=0，M3/M4为IN1=0、IN2=1；逻辑后退时互换。这里记录的是2026-10-13版本的接线/安装关系，其他车体布局可修改该掩码。

最大占空比从25%改为60%，每40ms变化1%，上升/下降各2.4秒；匀速段由1秒改为3秒，便于观察稳定速度是否仍卡顿。实际转速取决于电机、负载和供电，不保证与占空比线性对应。

四路PWM各自20kHz，载波相位按周期四等分错开，50μs周期内间隔12.5μs。每路在自身周期边界锁存占空比，PWM=0时同时强制关闭。相移分散开关时刻和瞬时负载，不替代电源电流能力，也不保证解决持续卡顿。

v2曾修正FMC映射：P3-1经FMC H19对应J15，而旧v1曾误用J20。72路映射见pins/adapter_acg138_mapping.json。v3继续使用正确映射。

## 🔌 v3 接线（沿用v2）

全部电机针号指**转接板GPIO0的P3**，不是ACG138底板P3：

| 电机 | PWM针号 / 球位 | IN1针号 / 球位 | IN2针号 / 球位 |
|---|---|---|---|
| M1 | P3-1 / J15 | P3-2 / H15 | P3-5 / Y21 |
| M2 | P3-6 / Y22 | P3-7 / AB21 | P3-9 / AA19 |
| M3 | P3-10 / AB20 | P3-28 / M16 | P3-31 / K21 |
| M4 | P3-16 / G20 | P3-19 / G17 | P3-39 / N18 |

| 共享连接 | 接法 |
|---|---|
| TB6612逻辑VCC | 3.3V，使用底板P10-22或转接板P3/P2-29 |
| 每块TB6612 STBY | 接3.3V，保持高，不占FPGA信号脚 |
| TB6612 GND / PGND | 与板卡地、电机电源负极共地 |
| TB6612 VM | 外部电机电源，匹配电机额定电压 |
| MPU9250 SCL / SDA | P10-1 D16 / P10-2 E16，沿用已读通接线 |
| MPU9250 VCC / GND | P10-22 / P10-21 |

**转接板P3/P2第11脚是5V、第12脚是GND、第29脚是3.3V、第30脚是GND**，PDF第2页已明确。不要把11脚当作3.3V逻辑电源。

所选电机脚位于Bank4/5/8，共用VCCADJ。转接板29脚的3.3V与FPGA信号电平电源不是同一概念：CST声明LVCMOS33不会改变VCCADJ。当前实测电压仍未知，使用前确认FMC G39/H40对应VCCADJ约3.3V；不要向VCCADJ反灌外部3.3V，也不要仅改CST或带电调整P20。

测试下载完成后等待3秒开始，顺序为M1/M2/M3/M4分别正反转，再四电机同时正反转。每次先PWM=0建立方向100ms，再2.4秒从0升到60%，保持3秒，2.4秒减到0，停车1秒。约92秒后永久停止，重新配置会重新开始。STBY一直由外部保持高；测试时将车轮悬空。

本目录独立电机工程的LED：D0心跳约2.68秒一周期，D1在测试期间亮，D2反转阶段亮，D3结束后亮。远控整合工程的D0～D3表示IMU状态，具体行为见其README。

如果D3已经亮，PWM=0是程序测试结束的预期行为。需要重新下载后在前92秒观察。起步及减速末尾很低的占空比仍可能低于电机启动/连续旋转阈值；判断持续卡顿时重点看3秒匀速段。D1表示流程进行，包括预设停车段。

## 🔌 本次实物接线反馈

已确认两套独立电源未共地，驱动VCC端未接。先将转接板P3-30与两块驱动GND共地，功率地仍直接返回外部12V负极；并确认TB6612 VCC实际有3.3V。STBY常高不代替VCC。板上3.3V端若为逻辑供电输入可接P3-29；若为稳压输出，先核对内部供电，避免直接并接电源输出。

正常v3最后四电机阶段已新增仿真复核，正反两个匀速段均持续20kHz/60% PWM，没有额外低频停顿；`make test` 中的 `tests/tb_final_all_continuity.v` 可重新验证。当前分级负载诊断工程位于相邻的 [`fmc_four_load_diag_direction_v2_20261019`](../fmc_four_load_diag_direction_v2_20261019/README.md) 目录。

## 🔍 如果修正后仍不动

先使用独立电机工程，便于LED指示。测试进行时检查：

1. D0应闪烁、D1应亮，确认FPGA时钟与测试状态在运行。
2. 逻辑前进时M1的P3-2应约3.3V、P3-5约0V；M3的P3-28为0、P3-31约3.3V。逻辑反向时互换。
3. P3-1应出现20kHz PWM，脉宽逐步变化。示波器/逻辑分析仪可确认；万用表只能看到约占空比乘以高电平电压的平均值，不能据此确认PWM频率。60%时3.3V逻辑PWM的理想平均约1.98V；这不是电机端电压。
4. 测到输入脚电平正确后，再检查TB6612 VCC约3.3V、STBY为高、VM及地连接。VM必须实际有电，STBY常高不能替代VM供电。
5. 仍在悬空匀速段持续卡顿时，在TB6612的VM与PGND之间测运行电压，并核对已报告12V/6A电源在此状态的实际输出。VM和PGND用足够载流能力的短线直接接外部12V电源，FPGA与驱动另外共地，避免电机电流通过FPGA信号地回流。同步观察D0/D1/D2是否像重新下载那样从头开始，区分FPGA重启与电机侧异常。
6. TB6612内置欠压检测与过热关断，反复停转需要排查电源掉压、限流、驱动温升和电机/驱动电流是否匹配。额定最大电流不能直接当作任意工况下的持续驱动能力。依据：[东芝数据手册](https://toshiba.semicon-storage.com/info/TB6612FNG_datasheet_en_20141001.pdf?did=10660&prodName=TB6612FNG)。不要把软件相移视为硬件供电问题已经解决。

本次未连接实板，无法确认你的实际电压、接线和电机输出状态。详细编译结果见 `BUILD_STATUS.md`。

## 🛠️ 编译与参数

目录放在英文路径，打开Gowin工程或执行 `gw_sh build.tcl`。器件GW5AT-LV60PG484AC1/I0，选项保留 `enable_dsrm=1`、`use_cpu_as_gpio=1`。SCL/SDA沿用开漏与3.3V上拉。

`rtl/four_motor_ramp_test.v` 默认MAX_DUTY_PERCENT=60、RAMP_STEP_MS=40、HOLD_MS=3000、INVERT_MASK=4'b1100、STAGGER_PWM=1、MODE=0（逐个再全部）、REVERSE_TEST=1。每次升降时间为最大百分比乘以步进时间。默认PWM每周期2500拍，60%高电平1500拍、相邻载波间隔625拍，停止阶段PWM强制0。

`make test` 验证四电机流程及真实50MHz PWM。v3仿真覆盖方向掩码、四相PWM、0/100%、停车/换向和真实50MHz下的20kHz/60%波形，另核对最终布局引脚。
