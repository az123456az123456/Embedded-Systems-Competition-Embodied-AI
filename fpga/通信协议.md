# FPGA ↔ RK3588 通信协议 v2

> 串口：115200 8N1，二进制小端序
> CRC：CRC-16/CCITT-FALSE，初始值 `0xFFFF`，多项式 `0x1021`
> 当前状态：RK3588 端、虚拟 FPGA、FPGA `top_robot_v2`（纯 RTL 仿真）均已实现并通过测试；待高云综合和实板验证。旧 `top_robot.v` 仅保留作 v1 回归。

---

## 一、帧格式

```text
AA 55 | CMD | SEQ | LEN | PAYLOAD | CRC_L CRC_H
```

| 字段 | 长度 | 说明 |
|---|---:|---|
| `AA 55` | 2 | 固定帧头 |
| `CMD` | 1 | 命令码 |
| `SEQ` | 1 | 发送序号，0~255 循环 |
| `LEN` | 1 | Payload 长度，最大 32 |
| `PAYLOAD` | 0~32 | 小端序数据 |
| `CRC` | 2 | 对 `CMD + SEQ + LEN + PAYLOAD` 计算 |

CRC 使用 CRC-16/CCITT-FALSE。标准测试向量：

```text
CRC16("123456789") = 0x29B1
```

## 二、下行命令：RK3588 → FPGA

### 0x01 SET_TWIST

Payload 共 4 字节：

| 字节 | 类型 | 名称 | 单位 | 含义 |
|---|---|---|---|---|
| 0~1 | int16 | `v_mm_s` | mm/s | 正值前进，负值后退 |
| 2~3 | int16 | `w_mrad_s` | mrad/s | 正值逆时针左转，负值顺时针右转 |

FPGA 按左右轮差速换算：

```text
v_left  = v - w × track_width / 2000
v_right = v + w × track_width / 2000
```

其中 `w` 单位为 mrad/s、`track_width` 单位为 mm。

建议安全范围：

```text
-3000 <= v_mm_s  <= 3000
-3000 <= w_mrad_s <= 3000
```

### 0x02 STOP

Payload 共 1 字节：

| 值 | 含义 |
|---:|---|
| 0 | 正常停车 |
| 1 | 看门狗超时停车 |
| 2 | 操作者停车 |
| 3 | 故障停车 |

FPGA 收到 STOP 后必须立即禁用 PID、清积分并停止 PWM。

### 0x03 SET_MODE

Payload 共 1 字节：

| 值 | 模式 |
|---:|---|
| 0 | 手动 |
| 1 | 避障 |
| 2 | 视觉控制 |
| 3 | 空闲 |

### 0x04 CLEAR_FAULT

无 Payload，用于清除可恢复故障和看门狗锁存。

### 0x10 HEARTBEAT

无 Payload，默认每 100 ms 发送一次。

FPGA 默认 500 ms 未收到有效 HEARTBEAT 或有效下行命令，必须进入安全停车。

## 三、上行数据：FPGA → RK3588

### 0x81 STATUS

Payload 共 12 字节，建议每 100 ms 上报一次：

| 字节 | 类型 | 名称 | 单位 |
|---|---|---|---|
| 0~1 | int16 | `speed_left_mm_s` | mm/s |
| 2~3 | int16 | `speed_right_mm_s` | mm/s |
| 4~5 | uint16 | `distance_cm` | cm，`0xFFFF` 表示无效 |
| 6~7 | uint16 | `yaw_centideg` | 0.01°，0~35999 循环 |
| 8~9 | uint16 | `flags` | 状态标志 |
| 10~11 | uint16 | `reserved` | 预留 |

Flags：

| Bit | 名称 | 含义 |
|---:|---|---|
| 0 | LINK_OK | 通信正常 |
| 1 | MOVING | 电机正在运动 |
| 2 | OBSTACLE | 当前检测到障碍 |
| 3 | ESTOP | 急停状态 |
| 4 | IMU_VALID | IMU 数据有效 |
| 5 | ULTRASONIC_VALID | 超声波距离有效 |
| 6 | WATCHDOG | 看门狗已触发 |
| 7 | FAULT | 存在故障 |

### 0x82 ACK

Payload 共 3 字节：

```text
ACKED_CMD | CODE | DETAIL
```

错误码：

| 值 | 名称 |
|---:|---|
| 0 | OK |
| 1 | BAD_COMMAND |
| 2 | BAD_PAYLOAD |
| 3 | NOT_READY |
| 4 | CRC_ERROR |
| 5 | WATCHDOG |
| 6 | ESTOP |

### 0x83 FAULT

Payload 共 4 字节：

```text
FAULT_CODE(uint16) | INFO(uint16)
```

## 四、安全要求

1. FPGA 必须验证帧头、长度和 CRC，错误帧不得执行。
2. RK3588 必须周期发送 HEARTBEAT。
3. FPGA 的通信看门狗必须独立于软核 CPU 或控制状态机。
4. 看门狗、CRC 连续错误和急停必须触发 `STOP`，并清 PID 积分。
5. `SET_TWIST` 受最大速度、最大角速度和加速度限制。
6. 退出视觉程序前发送 STOP；异常退出时依靠 FPGA 看门狗兜底。
