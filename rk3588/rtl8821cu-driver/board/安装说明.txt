RTL8821CU · ACG138 RK3588 · Linux 6.1.75 驱动安装包
日期：2026-10-17

一、适用对象

USB 网卡：RTL8821CU，lsusb 显示 0bda:c820。
系统：现有 Buildroot，aarch64，Linux 6.1.75。
编译器：BSP 原配 aarch64-none-linux-gnu-gcc 10.3.1 20210621。
内核配置 SHA256：
7114825305fb4b5f032a523d009ae4eaa321f1c816ff60f44eeaca3b9a0ec20f
以上架构、版本、编译器和配置指纹已与用户提供的板端输出核对。

这是独立驱动包，不含 boot.img/rootfs.img，不刷系统、内核或 FPGA。
板端不需要联网、gcc、内核源码、DKMS、apt 或重新编译。
本地交叉编译和静态检查已通过，尚未在用户的实板上加载、联网实测。

二、拷贝与安装

只需将 rtl8821cu-rk3588-6.1.75-driver-20261017.tar.gz 拷到板子的 /root/。
源码包是电脑端留档/重新编译用，不用拷到板子。
插好网卡后，在板端 root 终端逐行执行：

cd /root
tar -xzf rtl8821cu-rk3588-6.1.75-driver-20261017.tar.gz
cd /root/rtl8821cu-rk3588-6.1.75
sh install.sh --check
sh install.sh
iw dev

--check 只检查，不复制文件、不加载模块。
检查输出 PASS 后执行安装。安装成功输出 INSTALLED，会立即加载驱动，
并配置 Buildroot 下次开机自动加载；不需要重启。

当状态输出同时包含下面信息时，表示驱动已识别到网卡并创建网口：
Driver: LOADED (8821cu)
USB Wi-Fi: BOUND to 8821cu (...)
Wireless interface: wlan0
READY: USB driver bound and a wireless interface created.

wlan0 只是示例，也可能是 wlan1 或其他名字，以实际输出为准。
iw dev 应能看到 Interface 和 type managed。
“Driver: LOADED”单独出现仅代表模块已加载，不等于网卡已正常工作。
READY 也不代表已经连接路由器；Wi-Fi 名称、密码和 DHCP 属于下一步联网配置。
本包不写入 Wi-Fi 密码、不修改 IP、路由、现有网络管理服务或 FPGA RGMII 设置。

三、安装实际新增的三个文件

/lib/modules/6.1.75/extra/acg138-rtl8821cu/8821cu.ko
/etc/modprobe.d/acg138-rtl8821cu.conf
/etc/init.d/S35rtl8821cu

若系统提供 depmod，会同步更新 /lib/modules/6.1.75 下的模块索引；
若没有 depmod，开机脚本直接使用 insmod，仍可正常加载。
cfg80211、USB 等依赖已内置于此内核；无线固件包含在 8821cu.ko 中。
驱动采用 rtw_power_mgnt=0、rtw_ips_mode=0、rtw_enusbss=0，关闭相关省电模式，
用于减少后续小车控制与视频传输受无线休眠影响的机会；未改发射功率或地区限制。
保留解压目录，便于以后检查和卸载。

四、检查和排查

cd /root/rtl8821cu-rk3588-6.1.75
sh status.sh
dmesg | tail -n 60

status.sh 只读取信息，不会重置网口或改变网络。
如果 USB: 0bda:c820 not present，重新插好网卡后再次检查。
如果模块已加载、USB 已找到但没有网口，提供上述两条输出继续判断。
如果出现 Invalid module format / Unknown symbol，请提供内核日志，不要强制加载。
Kernel config mismatch 表示当前内核配置和此包不一致，脚本会停止，需重新匹配编译。
Existing different file / Other RTL8821CU modules 表示已存在其他版本，脚本会保留原文件并停止。
未连接路由器时没有 IP 地址是正常现象，不能据此判断驱动失败。

五、卸载

通过串口或本地终端执行较合适；卸载会断开这张网卡的 Wi-Fi。

cd /root/rtl8821cu-rk3588-6.1.75
sh uninstall.sh

只移除本包模块和两个加载配置。若模块正在使用且无法卸载，脚本会停止并保留文件。
若用户改过这三个安装文件，卸载会停止，避免误删用户修改；恢复本包对应文件后再卸载。
