# 项目需求与验收目标

> 2026 嵌入式系统竞赛选题三：基于 FPGA 的具身智能机器人实时感知与自主控制系统设计。

当前平台为 ACG138-RK3588-CORE，采用高云 GW5AT-60K FPGA 与 RK3588。FPGA 承担实时采集与执行，RK3588 承担视觉、交互和任务决策。

| 任务 | 验收目标 |
|---|---|
| 1 多传感器感知 | 摄像头采集与显示、IMU 数据读取、画面和姿态信息实时显示 |
| 2 运动控制 | 前进、后退、转向、定点旋转；使用编码器反馈验证运动闭环 |
| 3 实时避障 | 根据测距完成检测、减速、停车和绕障 |
| 4 自主导航 | 从起点到终点自主移动，支持避障和路径点导航 |
| 5 视觉目标识别 | 检测、跟踪人员或物体，实现指定目标跟随 |
| 6 智能任务执行 | 将目标搜索、语义指令与自主移动连接，例如寻找红色水瓶并靠近 |

当前代码与验收目标应分别评估：远控链路输出 PWM，ACK 不是实测轮速；三向超声波和导航仍需实车接入；Python 任务原型与手机远控尚未统一。最新阶段成果见 [技术报告](技术报告_20261020.docx)，工程入口和测试见 [仓库说明](../README.md)。

上述任务整理自仓库既有需求分析。原始官方选题指南未随仓库保存，正式参赛要求以该指南为准；旧迁移分析中的平台比较、方案猜测和评分百分比不作为当前工程要求。
