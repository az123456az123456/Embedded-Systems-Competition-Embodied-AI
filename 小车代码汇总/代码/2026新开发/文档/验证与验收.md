# 验证与验收

## 自动检查的范围

`tools/verify_source_tree.py` 检查版本目录、逐文件 SHA-256、禁入输出/密钥文件、二进制文件头、每版 README、Android 最终版本和 FPGA 当前工程引用。`tools/run_smoke_tests.py` 在临时目录执行当前 RK 前超声跟随/速度、Android 跟随与客户端，以及 FPGA 编码器 RTL 的已有测试；不连接真实硬件。

GitHub Actions 的绿色检查只证明这些源码检查和主机回归成功。它不运行专有 Gowin EDA、不验证真实相机/传感器、不安装板端程序、不驱动电机，也不证明所有历史版本完整可构建。
