# 比赛材料说明

此 GitHub 仓库可作为参赛材料中的**多平台源码与项目说明**。仓库名称不代表已获得官方认证，最终提交范围按官方指南核对。

## 对评审的阅读路径

1. 仓库根 README：项目名称、平台与当前入口。
2. 本目录 [完整项目说明](../项目说明.md)：系统分工、功能、参数、最终状态和验证边界。
3. 三个平台 README：当前可复现源码、历史版本和工程入口。
4. [构建与复现](构建与复现.md)、[通信与接口](通信与接口.md)：环境、依赖和数据流。
5. [版本沿革](版本沿革.md)、`版本索引.json`、`源码清单.json`：版本来源和文件身份。
6. [验证与验收](验证与验收.md)、GitHub Actions：已经做过什么，以及尚待哪些实车验证。

## 本仓库包含与不包含

包含可恢复的源文件、测试源码、引脚/时序约束、构建脚本、必要输入配置、版本说明和第三方许可。完整版本与局部补丁分别标记。

不包含 FPGA 位流、APK、模型、SDK/rootfs、编译输出、运行私密信息及原始日志。烧录/安装文件如比赛要求，应在完成版本核验后单独构建，不能用目录中缺少二进制来判断缺少源码。

官方报名/作品表、队员与指导教师信息、实物照片、演示视频、硬件清单和最终实测记录未由本次源码整理提供；应由参赛人按官方要求配套提交。不得将“待验收”功能写成“全系统实测完成”。

## 建议引用方式

提交时记录仓库 URL 与对应 Git 提交 SHA，使用该固定提交链接。评审可据清单确认源码；未来继续开发不应覆盖本次提交对应的历史。若需发布正式 release，应在最终动态验收后将状态和产物分发方式补齐。
