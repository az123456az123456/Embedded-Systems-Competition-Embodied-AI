# 通信与接口

## 手机到 RK

手机通过同一局域网访问 RK HTTP 网关（默认 8080），网关转发到本机感知/控制后端（默认 8082）。视频为 MJPEG，检测、地图、任务和控制为 JSON/HTTP。确切路由和字段以当前 `gateway/runtime.cc`、`perception/phone/phone_service.cc` 与 Android `RobotClient.java` 为准；本文不另外定义一套可能漂移的 API。

控制包含序号、任务/选择身份、前台租期及使能状态；视频选框使用检测框身份与帧身份。视觉持久显示不等于传感器新鲜，视频重连不应替用户重新使能。运行令牌由板端提供，仓库仅保留令牌文件路径和读取逻辑。

## RK 到 FPGA

RGMII 以太网承载摄像头、IMU/传感器、运动与导航协议。`common/` 保存共享编解码，`acg138_fpga_map_bridge/` 处理 ROS 到 FPGA 的局部图与执行协议，`gateway/` 与 `perception/phone/` 分别协调导航和手机控制。

导航使用局部栅格、目标/地图/会话身份、序号、CRC、运动许可及状态回执。与早期 NAV2/v39 协议相比，当前 NAV3 的字段和控制权不能通过版本号猜测兼容；混用前应核对两侧编解码源码、顶层/固件和握手。

## ROS 接口

基础数据包括 `/scan`、`/odom` 与 TF；地图/路径/任务由当前 launch、YAML 和节点源码定义。`robot-fpga-integration-20261102/deploy/run-chroot.sh` 连接宿主与 ROS 用户空间，采用受控设备绑定、独立挂载和 Unix socket/共享路径，原生网关本身不链接 ROS 库。

## 三类距离不要混用

- 前超声波跟随：0.3 m 目标，0.25–0.35 m 保持区间，不要求雷达匹配。
- FPGA v54 自主执行：150/70 mm 避障/后退阈值及 300 mm 脱离再规划。
- 雷达建图/导航/语义搜索：使用各自扫描、TF、车体与地图配置。

三者作用域不同。参数变化需同时核对状态机与时效条件，不能只改 UI 显示的距离单位。
