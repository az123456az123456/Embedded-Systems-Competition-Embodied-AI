# 第三方来源与许可

本项目使用多个第三方组件。源码中的原许可证、版权头和来源文件应保留；仅将源码上传 GitHub 不会自动改变其授权。整理工作不替作者指定整个工程的开源许可证。

| 组件 | 仓库中的位置/来源 | 处理 |
| --- | --- | --- |
| PicoRV32 | FPGA `softcore/vendor/picorv32.v`、upstream 元数据 | 保留上游版权头与许可声明 |
| RPLIDAR / Slamtec SDK | RK ROS `acg138_rplidar/vendor/` | 保留 LICENSE / LICENSE-Slamtec.txt |
| ROS filters / laser_filters / explore_lite 等 | 各 ROS workspace 的 src | 保留 package.xml 与随附 LICENSE/版权头，按上游条款使用 |
| JSON/HTTP/图像辅助代码 | vendor、include、common | 以各源文件版权声明为准 |
| libjpeg-turbo | perception/vendor/jpeg_turbo | 保留头文件、LICENSE 与来源 JSON；预编译 .a 不提交 |
| 字体 | perception/assets/FONT-LICENSE、font_atlas.h | 保留许可与源码内字模输入 |
| Gowin EDA / FPGA 工具原语 | 外部厂商开发环境 | 不随仓库重新分发厂商工具或其生成网表 |
| Rockchip BSP / RKNN / RGA / RKAIQ / RKLLM | 外部匹配 SDK | 不分发预编译库、SDK 或模型权重；按厂商条款自行准备 |
| Android SDK / JDK | 外部构建工具 | 不提交 SDK、APK 或签名密钥 |

`ov5640_af.hex` 是旧工程已使用、HDL 直接读取的固定自动对焦初始化输入，并非本项目软核编译输出。其设备固件来源/再分发条款应由原硬件资料提供方核对；不据此对该设备固件授予新的许可证。参赛提交与任何进一步商业发布应分别确认组件许可和模型/素材使用权。

未找到单独许可证的自研/历史文件保留原权利状态；仓库未给出允许他人无限制再使用的统一授权。提交比赛前由权利人确认比赛所需的提交/评审使用授权。
