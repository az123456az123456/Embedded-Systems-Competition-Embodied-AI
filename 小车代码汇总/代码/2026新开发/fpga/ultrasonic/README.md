# 超声波测距模块（已仿真通过 ✅）

| 文件 | 说明 |
|---|---|
| `ultrasonic.v` | HC-SR04 测距：触发脉冲 + 回波计时 + 距离换算 + 超时保护 |
| `tb_ultrasonic.v` | 测距/超时测试（PASS）|

## 接口
- 输入: `trigger`(触发脉冲), `echo`(回波)
- 输出: `trig`(触发), `distance_cm`[15:0], `done`(完成脉冲), `busy`

## 测试结果
- echo 100000拍(2ms) → 34cm ✅
- echo 200000拍(4ms) → 68cm ✅
- 无回波 → 超时输出 0xFFFF ✅

## 换算公式
距离(cm) = echo高电平时钟数 × 343 / 1_000_000
（声速 343m/s，50MHz 时钟）

## 注意
- 触发脉冲 10µs；回波最大测量距离约 5m（超时 30ms 可调）
- 两次测量间隔建议 ≥ 60ms（避免串扰）
- 超时输出 0xFFFF 表示无回波/超量程
