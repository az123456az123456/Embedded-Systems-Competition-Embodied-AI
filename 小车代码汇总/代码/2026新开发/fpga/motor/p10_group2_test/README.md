# ACG138：P10 第二组单电机测试

`motor_group2_test.gprj` 是独立 Gowin 工程，顶层为 `motor_group2_test`。器件设置沿用项目内的摄像头工程：GW5AT-60B / GW5AT-LV60PG484AC1/I0。

| 信号 | 排针 | FPGA 焊球 | 运行时行为 |
|---|---|---|---|
| motor_pwm | P10-4 | F16 | 20kHz、25% 占空比 |
| motor_in1 | P10-5 | A16 | 1，约 3.3V |
| motor_in2 | P10-6 | A15 | 0，约 0V |
| motor_en | P10-7 | F14 | 1，约 3.3V，总使能 |
| GND | P10-21 或 P10-23 | — | 与驱动板信号地共地 |
| clk50m | 板载时钟，无需外接 | F13 | 50MHz |

这些输出全部属于固定 3.3V 的 Bank1，不需要电平转换，也不用修改 P20。

配置完成后，全部控制输出先保持低电平 2 秒。随后 IN1 变为 1，等待一个 PWM 周期（50µs），再打开总使能，以 25% 占空比运行 3 秒。结束后 EN、PWM、IN1、IN2 全部回到 0，并保持停止；重新配置 FPGA 可重新开始。实际旋转方向由电机接线和驱动板真值表决定，本程序不自动反转。

按常见的 PWM / IN1 / IN2 接口和 EN 高有效编写。若驱动板的使能极性或控制真值表不同，需要先修改对应输出定义。P10 信号只接驱动板的逻辑输入；电机接驱动板功率输出，由驱动板单独提供电机电源。配置完成前 FPGA 引脚可能为高阻，建议在驱动板 EN 端加 10kΩ 下拉，使默认状态为停机。若驱动板已有合适的下拉，无需重复添加。

## 编译与使用

1. 用 Gowin IDE 打开 `.gprj`，确认器件与实板及原工程一致，顶层选择 `motor_group2_test`。
2. 运行综合、布局布线；用生成的 `.fs` 做 SRAM 临时下载，下载完成后测试会自动开始。先用示波器或逻辑分析仪核对三个控制信号和 EN。
3. 下载这个独立工程会替换当前 FPGA 逻辑，原来使用 P7 的摄像头等功能会暂停。需要同时保留 P7 功能时，把模块加入原工程并在原顶层实例化，将四个输出引出为顶层端口，再合并 `.cst` 约束；复用原来的 50MHz 时钟。不要在原工程中复制第二条同名时钟约束。

可修改源码顶部的 `DUTY_PERCENT`（0～100）、`PWM_HZ`、`WAIT_MS`、`RUN_MS`。板载时钟仍为 50MHz，不要随意修改 `CLK_HZ`。默认一个周期为 2500 拍，高电平 625 拍，即 50µs 周期、12.5µs 高电平。占空比会按整数时钟拍向下取整；参数应保持计数结果在 32 位范围内。

```bash
iverilog -g2012 -s tb_motor_group2_test -o /tmp/acg138_motor_group2_tb motor_group2_test.v tb_motor_group2_test.v

```
