# 四电机分级负载诊断

> 2026-10-13 · 独立电机测试 · 12V电机 / 外部12V 6A

## 已确认的接线缺项

用户报告FPGA与电机使用两套独立电源，驱动仅接外部12V正负极，没有连接FPGA信号地；STBY为3.3V，VCC端未接。缺少显式共地是确定问题，VCC实际供电也必须核实。

断电后，外部12V正极接两块驱动VM，负极直接接两块驱动GND/PGND；另将转接板GPIO0/P3-30接驱动GND，建立FPGA信号参考。功率回流直接走外部电源线，FPGA地线不承担电机功率回流。

TB6612的VCC为逻辑电源，STBY为逻辑输入，STBY接高不替代VCC供电。确认驱动板的3.3V/VCC端是逻辑供电输入，并测得转接板P3-29对P3-30约3.3V后，再用它供VCC。若模块上的3.3V端是板载稳压输出且已经内部供VCC，先对驱动GND测量VCC实际为3.3V，避免把两个稳压输出直接并接。VM才使用12V。

转接板第11脚为5V，第29脚为3.3V，第12/30脚为GND。接线仍采用v2/v3已跑通的12路电机信号，不改变针号或3/4方向掩码。详细信号表见fmc_motor_load_diag.cst。

以下P3均指**FMC转接板GPIO0/P3**：

| 电机 | PWM | IN1 | IN2 |
|---|---|---|---|
| M1 | P3-1 | P3-2 | P3-5 |
| M2 | P3-6 | P3-7 | P3-9 |
| M3 | P3-10 | P3-28 | P3-31 |
| M4 | P3-16 | P3-19 | P3-39 |

四路信号所在Bank4/5/8使用VCCADJ，需实际约3.3V；CST中的LVCMOS33不会调整硬件电压。P3-29电源与VCCADJ是不同网络，不能向VCCADJ反灌电源。

## 诊断位流过程

优先补齐共地并确认VCC，再用已有v3复测。若需要定位增加负载时的故障，可下载本诊断版：

1. 等待3秒，M1从0缓升至60%，约2.4秒。
2. 到60%后，每隔1秒依次加入M2、M3、M4。
3. 四个全部加入后，60%持续保持约12秒，无反向命令或预设停车。
4. 全部缓降至0并停止，不循环，总时长约24秒。

D0～D3分别对应M1～M4的非零运行指令：依次显示一个、两个、三个、四个灯亮。四灯持续亮而车轮同时卡顿，说明在数字指令层没有计划停车，需要查驱动端VM/VCC/GND及驱动状态；LED不能代替PWM引脚波形测量。若灯重复从熄灭和等待阶段重新开始，需要另外排查FPGA配置/供电重启。

本诊断版STBY仍由外部常高，不增加使能脚。新增电机在加入时直接进入60%，用于观察负载加入，保持车轮悬空。它是台架诊断程序，不是机器人运行控制。

## 验证与限制

仿真覆盖1/2/3/4个负载加入、LED指令、3/4方向、60%持续PWM、停车；PWM周期内40%的低电平是正常调制，不是低频断电。另对正常v3的“先四个单独、再四个一起”完整流程补测，最终两方向匀速段均无额外PWM停顿。
