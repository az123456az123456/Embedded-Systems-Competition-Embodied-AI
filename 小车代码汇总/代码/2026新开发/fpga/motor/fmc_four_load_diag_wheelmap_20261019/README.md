# 四电机分级负载诊断：实际轮位修正版

> 2026-10-19 · 用户确认 M1右后、M2左后、M3右前、M4左前。

## 🔌 接线与方向

P3 指 FMC 转接板 GPIO0/P3。沿用原来的信号针脚，仅将方向掩码从 1100 改为 0101（bit0 对应 M1），反转右侧的 M1/M3。

| 电机 | 实际位置 | PWM | IN1 | IN2 | 运行方向电平 IN1/IN2 |
|---|---|---|---|---|---|
| M1 | 右后 | P3-1 | P3-2 | P3-5 | 0 / 1 |
| M2 | 左后 | P3-6 | P3-7 | P3-9 | 1 / 0 |
| M3 | 右前 | P3-10 | P3-28 | P3-31 | 0 / 1 |
| M4 | 左前 | P3-16 | P3-19 | P3-39 | 1 / 0 |

相对旧位流，只改变 M1、M4 的方向；M2、M3 保持原方向。左右电机镜像安装、同侧电机引线极性一致时，四轮应推动小车同向行驶。前进还是后退仍取决于实际电机两根线的接法；若四轮统一向后，可整体反向，若仅一轮反向，应核对那一路引线。

STBY 继续外接常高，驱动逻辑 VCC 使用已确认的 3.3V 供电。FPGA 信号地与驱动 GND 共地，电机功率回流走外部电源。

## ▶️ 自动测试顺序

烧录后自动运行，先架空车轮：

1. 等待约 3 秒，M1（右后）用约 2.4 秒升至 60%。
2. 每隔 1 秒依次加入 M2（左后）、M3（右前）、M4（左前），新增电机直接进入 60%。
3. 四轮保持约 12 秒，然后一起减速至 PWM=0；不反转、不循环。

PWM 仍为 20kHz，最高 60%；D0～D3 对应 M1～M4 的运行指令。停止后重新配置 FPGA 可再执行一次。本版只包含电机诊断，不包含摄像头、IMU 或手机遥控。
