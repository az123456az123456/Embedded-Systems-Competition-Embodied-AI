# 四电机分级负载诊断：方向修正 v2

> 2026-10-19 · 根据用户实测：上一轮位修正版 M1/M3反向，M2/M4正确。

只相对上一版翻转 M1、M3，保持 M2、M4；INVERT_MASK 从 0101 改为 0000（bit0=M1）。物理安装朝向不能替代实际电机引线极性，本版依据实测修正。

| 电机 | 位置 | PWM | IN1 | IN2 | 运行电平 IN1/IN2 |
|---|---|---|---|---|---|
| M1 | 右后 | P3-1 | P3-2 | P3-5 | 1 / 0 |
| M2 | 左后 | P3-6 | P3-7 | P3-9 | 1 / 0 |
| M3 | 右前 | P3-10 | P3-28 | P3-31 | 1 / 0 |
| M4 | 左前 | P3-16 | P3-19 | P3-39 | 1 / 0 |

P3 是 FMC 转接板 GPIO0/P3；所有引脚不变。保持现有已验证的驱动供电、共地和 STBY 常高连接。

烧录后会自动运行，请先架空车轮：等待约3秒，M1用约2.4秒加速至60%；随后每隔1秒加入M2、M3、M4（新增通道直接进入60%）；四轮一起保持约12秒，全部缓降至PWM=0停止，不循环。PWM仍为20kHz，最高60%。这是独立电机诊断，不包含摄像头、IMU和手机遥控。

打开 fmc_motor_load_diag.gprj，顶层 fmc_motor_load_diag；或运行 gw_sh build.tcl。位流位于 impl/pnr/fmc_motor_load_diag.fs。make test 验证全部通道方向、分级启动、持续PWM与停止；最终编译与引脚检查见 reports/source_bitstream_sha256.json。未进行本版实车烧录验证。
