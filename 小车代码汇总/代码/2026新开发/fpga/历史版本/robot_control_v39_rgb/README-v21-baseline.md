# ACG138 v21 连续弧线与倒车方向约定

基于已审计 v20，仅新增 MOT3/ACK3 连续路径弧线协议。摄像头约40 FPS试验时序、P3接线、默认轮组掩码、编码器直线校正、IMU、超声波和 A* 固件均保持 v20。

MOT3 外侧轮速度为 -600～600 permille，曲率为 -256～256 Q8。正曲率是画面/摇杆的右方，即使倒车也相同；负曲率是左方。内侧轮减速量为 `floor(abs(速度)*abs(曲率)/512)`，因此正常弧线两侧同向，内侧速度不低于外侧的50%。左后退：左轮较慢倒退、右轮较快倒退。速度为0时两侧立即停止。

MOT1 保持物理左右轮有符号速度语义；MOT2 保持视觉跟随航向语义，避免改变原地旋转、导航及航向保持的坐标约定。MOT3仅用于新上位机连续路径弧线。ACK3同样回报已应用的物理左右两侧基础PWM占空比（含加减速过程，单轮编码器微调另计），不把它重新解释为曲率。

无自动开机运动；仍需停车配置握手、有效序号、匹配轮组掩码及持续新命令。500ms失联停车、换向死区、PWM=0停车、限幅和编码器反馈策略保持。

打开 `robot_control_v21.gprj`；命令行使用 `tools/build_softcore.sh`。构建结果和真实时序见 `reports/release_verification.json`。`make test-release` 包含原回归、全范围 MOT3 黄金计算及 MOT1/MOT2 逐周期参考比较。当前工程不是板上实测结果，需先架空轮子验证。

物理轮组通过手机设置下发；本版不擅自交换M2/M3或编码器通道。历史接线说明保留供核对，以实际手机设置与校准为准。
