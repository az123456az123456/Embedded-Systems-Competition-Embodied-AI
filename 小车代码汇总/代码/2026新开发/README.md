# ACG138 具身智能移动机器人 · 2026 开发源码

基于 **高云 GW5AT-60 FPGA、RK3588 与 Android** 的异构移动机器人项目。该目录是比赛材料对应的源码主入口，按平台保存最终源码和可恢复的历史版本。

| 平台 | 当前源码 | 作用 | 当前验证状态 |
| --- | --- | --- | --- |
| FPGA | [v54 · 150/70 mm](fpga/v54_150_70_20261104/README.md) | 双目采集、传感器、RISC-V 导航、电机与运动保护 | 已有综合/布局布线通过记录；该最终位流尚未烧录验收 |
| RK3588 | [v143](rk3588/v143_20261104/README.md) | YOLO、视频/HTTP 网关、ROS 2 建图导航、目标跟随 | 与串口读取的板端主程序、网关版本核对一致；完成静态检查 |
| Android | [v143 / 1.2.43](上位机/v143_1.2.43_20261104/README.md) | 无线遥控、视频选框、地图、语义任务和操作反馈 | 源码与构建记录齐备；本版手机覆盖安装和动态验收待完成 |

**当前目标跟随：** 摄像头选中目标并保持其居中；前超声波确定距离，保持约 **0.3 m（3 dm）**，0.25–0.35 m 静止。转向侧检查对应超声波。该模式不依赖雷达空间检查；雷达仍服务于建图、导航与语义搜索。目标丢失、观测过期或指令失效时停车，取消后不自行恢复。详见 [完整项目说明](项目说明.md)。

## 阅读与复现

1. 阅读 [项目说明](项目说明.md)，理解平台分工、功能及最终状态。
2. 按 [构建与复现](文档/构建与复现.md) 准备工具链和外部依赖。
3. 用 [版本沿革](文档/版本沿革.md) 和各平台 README 查找指定历史版本。
4. 运行 `python3 tools/verify_source_tree.py` 检查纯源码规则和文件清单；运行 `python3 tools/run_smoke_tests.py` 完成主机回归。
5. 按 [验证与验收](文档/验证与验收.md) 完成硬件动态验收，并在 [比赛材料说明](文档/比赛材料说明.md) 中核对材料范围。

## 归档规则

保留 C/C++、RTL、Python、Java、测试源码、工程文件、输入配置、约束与构建脚本。不包含位流、APK、可执行程序、目标文件、预编译库、模型/权重、SDK/rootfs、压缩安装包、运行令牌、签名密钥、缓存或日志。唯一保留的 `.hex` 为 `camera/ov5640_af.hex`：它是 HDL 读取的固定传感器初始化输入表；软核编译生成的 `firmware*.hex` 均已排除。

历史说明保存在各工程 `历史说明.md`；其中旧路径、报告、产物链接及完成状态只作当时背景。源码补丁、实验分支及未找到完整源码的版本均单独标识，未用其他版本补造。文件身份由 [源码清单](源码清单.json) 记录，外部依赖和授权见 [第三方说明](文档/第三方与许可.md)。
