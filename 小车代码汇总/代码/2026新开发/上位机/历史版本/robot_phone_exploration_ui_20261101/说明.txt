ACG138 手机端 v1.2.24 — 探索建图入口适配

本包解决手机入口与请求问题，供用户安装查看；RK 自主探索的完整运行连接仍待实现和实板验收，不能把本包理解为自主探索整套系统已交付。

已完成
1. 导航页、辅助功能页删除“保持直行”，同位置改为“探索建图”。
2. 打开软件、连接 RK、切到地图页均不发送建图启动请求。使能后，明确点击按钮才发 mapping-start。
3. 使用原有 /api/navigation、配对与会话；不发 straight，不回退为旧版 explore，不自动使能，不产生探索用的直接 DRIVE。
4. 探索请求进行中/运行时显示“结束建图”。结束立即撤销手机运动意图并发送原有 STOP/disarm，独立提交 mapping-stop，由 RK 在确认停稳后处理保存/加载。HTTP 接受不等于保存成功或 FPGA 已加载。
5. 探索期间切换摄像头/导航显示及辅助功能翻页不取消探索。摇杆接管、停车等原有停止入口保留。
6. 保留 v1.2.23 摄像头等比放大、顶部居中状态、黑色选中/水波、回弹、全面屏修复和原签名。
7. 只有 RK 状态明确提供 LOADED、map_commit_confirmed=true，且 loaded_map_session/revision 与显示地图相符、状态新鲜，导航画面上方才显示“地图已载入 FPGA”。这是界面消费条件，当前 RK 还未完整提供此状态。

实际使用边界
- 当前旧 RK 不支持探索接口时，点击会提示“RK 尚未接入探索建图服务，请更新 RK 整合程序”，不会启动旧直行。
- 新 RK 草稿已添加独立能力检查；只有真实探索/结束保存协调器已接入才允许广告支持。不能为了点亮按钮强行写 supports_exploration_mapping=true。
- 尚未完成：将 Gateway 与 ROS 探索/授权/保存地图协调器接入统一 YOLO 启动程序；ROS 实时地图显示整合；完整 Jazzy 构建、安装、实车闭环。
- 当前未发现 /dev/ttyUSB*；本轮未连接或操作 RK/FPGA，不含 RK 安装包、不改位流、不重建 rootfs。

验证
见 reports/release-verification.json。手机 View、真实 RobotClient（替换 HTTP 传输）、RK 真 Gateway 回环 HTTP 测试与 APK 编译签名检查通过；不是 Android 真机或车体实测。
