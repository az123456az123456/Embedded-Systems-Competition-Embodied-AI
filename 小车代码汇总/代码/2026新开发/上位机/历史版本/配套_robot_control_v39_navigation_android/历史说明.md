# ACG138 Android v12.10：开始与结束导航

包名 `cn.acg138.robotphone` 不变，版本 `1.2.10 / code 23`。安装 `dist/ACG138-Robot-Control-v12.10.apk` 可覆盖原 v12.9，签名相同，保留配对码、地址和已经调好的轮组设置；无需卸载旧软件。

## 操作

1. 按总包说明安装并启动 RK v23 导航服务。观察模式可以看地图，但不能发起自主运动；实际车速、制动和控制标定未确认时，也不会因为升级自动开启导航。
2. 手机连接原地址和配对码，打开底部“导航”。切换页面仍会停车并停用电机，进入后需要明确按“使能电机”。
3. 按“开始导航”。已有目的地时启动该目标路线，没有目的地时请求自主探索。RK 会重新检查地图、传感器、车体空间、IMU、编码器、电机 ACK 和手机前台控制权；不满足条件时显示原因。
4. “结束导航”立即取消本地等待中的启动/点选请求，随后发送停车及停用电机；迟到的请求和响应不会恢复导航。再次运动需要重新使能。
5. 仍可点选地图内已探明、空间足够的白色区域直接前往。摇杆随时接管；红色“停车”一直可用。失焦、切后台、断线和触控取消仍会停止控制。

导航页同时显示“开始导航”和“结束导航”。感知页第一组中的“手动差速”替换为“开始导航”，第二组中的“航向保持”替换为“结束导航”；每组仍为四个宽按钮，滑动翻页及滑动时的灰色页码点保留。“手动接管”按钮也已移除，接管由摇杆完成。

保留完整不裁剪视频、持续橙色选框、跟随目标、姿态归零、静止校准、原地顺/逆时针旋转、大摇杆和黑白配色。导航运行状态独立于点选目标，没有目的地对象时也显示规划、行进、扫描、停车或拒绝原因。

## 通信顺序

“开始导航”先在原控制队列完成一次零速度 DRIVE；成功后，由独立导航线程发送：

```json
{"op":"start","session":"当前控制会话","intent_seq":123,"nav_seq":1}
```

发送地址为 `POST /api/navigation`，沿用配对码认证。`intent_seq` 是刚刚成功的零速度 DRIVE 控制序号，`nav_seq` 与地图 goto 共用递增序列；start 不编造地图坐标。RK 要求该零速度意图仍新鲜、没有被后续手动、停车、重新使能、配置或会话变化替代。等待导航响应时，控制线程仍以约 50 ms 周期发送 idle 保活。

结束操作先增加本地意图代数并清空等待队列，再串行发送 `/api/control` 的 `stop` 和 `disarm`。启动/点选响应、遥测导航状态及结束通知还使用共同的本地锁排序，避免迟到响应覆盖“已结束”界面。不会自动重新发送启动请求。

开始功能要求 RK 遥测声明 `supports_start_stop=true`、`start_protocol_version>=2`。旧 RK 服务仍可使用原有视频和手动控制，但开始导航会提示先安装配套更新。地图 goto 继续绑定实际显示的坐标会话、版本和栅格中心坐标，地图新鲜度和安全间距校验保留。
