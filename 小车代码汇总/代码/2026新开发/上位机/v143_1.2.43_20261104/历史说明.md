# Android 手机上位机 v143 / 1.2.43

配套 RK 的前超声波目标跟随：目标距离 0.3 m，静止区间 0.25–0.35 m；摄像头选择并对准目标，界面和通信逻辑均包含在 `src/` 中。

源码入口：`AndroidManifest.xml`、`src/cn/acg138/robotphone/`、`res/`。包名 `cn.acg138.robotphone`，versionCode 56。

使用 JDK 17、Android SDK android-35 和 build-tools 35.0.0；设置 `ANDROID_SDK_ROOT` 与现有签名文件 `SIGNING_KEYSTORE`，运行 `./build-apk.sh`。本目录不包含 APK、构建目录、SDK 或签名密钥。主机端测试脚本为 `test-*-host.sh`。
