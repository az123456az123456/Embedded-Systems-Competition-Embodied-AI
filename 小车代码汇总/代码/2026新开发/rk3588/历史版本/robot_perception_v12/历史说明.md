# RK3588 双目 YOLO＋IMU 窗口

> 当前版本：v10.2-yolo11-30fps · 2026-10-19

## 🖥️ 功能与入口

原生 C/C++ Wayland 窗口，显示双目摄像头、目标框、IMU 姿态和加速度。采集、预览与三核 NPU 推理分别调度，识别处理最新完整双目帧；窗口保留约 33ms 的目标刷新间隔，并按刷新期限调整轮询等待。

板端安装位置默认 `/root/perception-dashboard`，统一入口：

```sh
./run-dashboard.sh -0
./run-dashboard.sh -90
./run-dashboard.sh -0 --no-detect
```

`run-dashboard.sh` 使用该安装目录中的 `perception-dashboard.aarch64` 和 `run-perception.sh`。完整更新使用相邻 [YOLO11s／30FPS 安装目录](../acg138-yolo11-30fps-rk3588-20261019/README.md)；本目录是编译源码。

默认模型为安装目录的 `model/yolo11s-int8-rk3588.rknn`，标签为 `model/coco_80_labels_list.txt`。可用 `MODEL_PATH`、`--model`、`LABELS_PATH` 覆盖；模型权重需要另行准备。启动器复用板端的 `librknnrt.so`、现有 ISP 接收链路和 Wayland 会话，保留 `--camera`、`--interface` 等参数。`CAMERA_TARGET_FPS` 仅描述接收输出的标称间隔，实际传感器速率由 FPGA 位流决定。

## 🔧 源码构建与测试

在本目录执行：

```sh
make
make test test-launcher test-fast test-ui-render
./build/perception-dashboard --preview build/preview.ppm
```

主机构建需要 C/C++ 编译器、Wayland 开发头文件与库；默认不启用 RKNN。`tests/` 覆盖 IMU、颜色与预处理、双目调度、UI 和启动器；`reports/` 保留已有验证记录。

ARM64 构建使用 `sh scripts/build-arm64.sh`，可指定 `CROSS_COMPILE`、`WAYLAND_INCLUDE`、`WAYLAND_LIB`、`RKNN_INCLUDE`、`RKNN_LIB`。自动搜索兼容的外部 `bsp_r4`、`gst-dev` 和 `YOLO/rknn_model_zoo`；所需 SDK 不随本源码提供。输出为 `build/perception-dashboard.aarch64`，板端继续使用其匹配的运行库。

## ✅ 验证边界

YOLO11s INT8 在已验证 20FPS 采集下，双目识别约 19.5～20FPS。30FPS 配套程序已构建、通过主机测试；现有记录未包含完整实板验收。实际采集、显示与识别 FPS 应分别查看 `FASTPATH`、`PERF` 和 `STAGE`，不能仅由窗口调度测试推断板端速度。

UI 字体与 Wayland 协议来源、许可证分别保留在 `assets/` 和 `vendor/`。
