# ACG138 自动起步与局部导航 v25

沿用统一入口 `sh /root/perception-dashboard/run-dashboard.sh -0`（横置 `-90`）。手机先使能电机，再点开始导航；进程启动本身不发起运动，也无需人工先转一圈。完整接线、更新与回滚见上级目录的“安装与导航说明.txt”和更新包的“使用说明.txt”。

无目标点的探索先停稳等待新观测。当前方及两侧距离允许、没有已知碰撞时，按不超过0.06 m/s、每段0.10 m的直行小步积累观测；上限1.20 m或60秒。不会把未知地图伪造为空闲，不能把该有限传感器反应模式视为全车盲区无障碍保证。已有观测形成可通行地图后，由FPGA中的同一份A*寻找路径，RK不运行另一个A*。地图点选继续要求已知可通行目标。

开始导航不再要求当前点周围整圈膨胀圆已被观察。每个实际转动仍验证新进入的车身区域；连续角点包络包含采样角之间的圆弧。遇前障先停稳，按可用侧空间选向，分段目标25°；已有路线时寻找前方回归点，初始尚无路线时进入独立观察/绕行分支，不能验证转动空间就停车等待。

同侧编码器轮速改用250 ms物理时间窗口，并设0.01 m/s比较下限，保留真实卡轮、反向和持续失配锁存。60527.7 CPR、(-1,+1,-1,+1)、当前手机验证的轮组、用户固定车体外廓和动态标定保持原值。保留v23.2的FPGA设备时钟IMU/编码器对齐及首个故障证据。

v25 FPGA仅改四个超声波合成文件，使用两次有效远观测的保守实际值并保留真实观测年龄；摄像头、IMU、电机、编码器和A*固件保持冻结v24的相同代码与引脚。手机APK、模型和摄像头参数无需更换。

手动遥杆/旋转仍为直接操控，没有新增超声波急停或自动绕行；目标跟随有测距停车门禁；完整绕障仅在自动导航。所有模式仍保留各自的租约/通信失联停车机制。

`make test` 包含真实三束观测自动起步到实际FPGA A*、连续转动包络、微小IMU波动、固定窗口编码器判定、原有导航/时钟对齐/HTTP仲裁/POSIX与BusyBox启动器回归。`make arm64` 使用BSP工具链。独立审查复现及验证日志在reports中。所有结果为离线验证，尚未实车验收。

当前是64×64局部栅格导航，尚无全局闭环SLAM、环境匹配或掉电重定位；摄像头用于YOLO目标跟随，地图来自超声波与里程计。
