Read/checked 2026-10-29; primary sources only.

1. ROS 2 target platforms, language/library baselines and LTS dates:
   https://github.com/ros-infrastructure/rep/blob/master/rep-2000.rst
   https://raw.githubusercontent.com/ros-infrastructure/rep/master/rep-2000.rst
   Humble May2022-May2027 / Ubuntu22.04 ARM64; Jazzy May2024-May2029 /
   Ubuntu24.04 ARM64. Buildroot is not a supported binary-package target.
   Jazzy Ubuntu Python3.12, Humble Ubuntu Python3.10; native port must build
   all Python C extensions for its own chosen target Python.

2. ROS Jazzy official release announcement (LTS 2029, Noble arm64 Tier1):
   https://www.openrobotics.org/blog/2024/5/ros-jazzy-jalisco-released

3. ROS official image tags/architecture and OSRF Dockerfile:
   https://hub.docker.com/_/ros/
   https://github.com/osrf/docker_images/blob/master/ros/jazzy/ubuntu/noble/ros-base/Dockerfile
   Valid tag ros:jazzy-ros-base-noble; amd64 and arm64v8. Tags move; exact
   digest must be inspected on build PC and recorded, never invented.

4. Official ROS cross compilation documentation:
   https://github.com/ros2/ros2_documentation/blob/jazzy/source/How-To-Guides/Cross-compilation.rst
   https://raw.githubusercontent.com/ros2/ros2_documentation/jazzy/source/How-To-Guides/Cross-compilation.rst
   ros-tooling/cross_compile is no longer supported; buildx multi-platform
   images is documented as an alternative.

5. Docker device/capability/run restrictions:
   https://docs.docker.com/engine/containers/run/

6. Buildroot package integration/reference (package recipe is not ROS support):
   https://buildroot.org/downloads/manual/manual.html#_infrastructure_for_cmake_based_packages
   Native ROS underlay needs host ament/rosidl generators + target rcl/rclcpp,
   rmw/DDS, Python/dependency packages and ABI validation. No all-in-one
   native cross-compiled ROS image has been produced by this delivery.
