## 1. 导航模块

| 文件 | 作用 |
|---|---|
| `navigation.py` | A* 规划、栅格地图、差速里程计、路径点控制器 |
| `nav_demo.py` | 无板卡导航演示（虚拟 FPGA） |
| `test_navigation.py` | 导航单元测试 |

运行：

```bash
cd 小车代码汇总/代码/2026新开发/rk3588
python nav_demo.py --obstacles "1500,1500,250;2500,2500,200" --duration 30
```

支持中文目标区域：

```bash
python nav_demo.py --instruction "走到右上角" --duration 30
python nav_demo.py --instruction "停止"
```

## 2. 中文语义解析

| 文件 | 作用 |
|---|---|
| `semantic_parser.py` | 中文 → `SemanticIntent(action/target/color/zone)` |
| `test_semantic_parser.py` | 解析单元测试 |

支持示例：

```text
"找到红色水瓶"  -> SEARCH target=bottle color=red
"跟着那个人"    -> FOLLOW target=person
"停止/停车"     -> STOP
"走到左上角"    -> GOTO zone=top-left
```

## 3. 与任务6 的接入

```bash
python task6_mission.py --instruction "找到红色水瓶" \
    --model /path/to/yolov8n.pt --no-reid
```

`--instruction` 会自动覆盖 `--target` / `--target-color`。
